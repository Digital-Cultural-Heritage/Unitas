Android

Installer aplikasi Android (.apk)

Pasang aplikasi native Unitas langsung di HP Android untuk pengalaman paling ringan dan notifikasi penuh.

Unduh Unitas untuk Android (.apk)

Cara pasang di Android

1
Ketuk tombol unduh di atas dan tunggu file .apk selesai tersimpan.
2
Buka file tersebut; jika diminta, izinkan Install dari sumber ini di pengaturan browser.
3
Buka aplikasi Unitas dan masuk menggunakan email kampus @unud.ac.id.
Atau coba langsung di browser (Web App)

iPhone & iPad (iOS)

Web App / PWA via Safari (tanpa App Store)

Apple tidak mendukung pemasangan file .apk. Pengguna iPhone/iPad bisa langsung menjalankan Unitas di Safari dan menambahkannya ke Layar Utama.

Buka Unitas di iPhone / iPad

Jadikan seperti aplikasi di iPhone

1
Ketuk Buka Unitas di iPhone / iPad di atas lewat browser Safari.
2
Ketuk ikon Share di bar bagian bawah Safari.
3
Pilih Add to Home Screen (Tambah ke Layar Utama) lalu ketuk Add.
Satu tautan pintar untuk seluruh alumni Universitas Udayana — Android & Apple.
